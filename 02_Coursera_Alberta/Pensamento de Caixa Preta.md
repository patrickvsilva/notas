Mentalidade de tratar uma classe como uma caixa opaca: o consumidor fornece entradas e obtém saídas via métodos, sem precisar conhecer a representação interna dos atributos nem como os métodos calculam o resultado.

## Implicação
- O *como* fica interno; o *o quê* (contrato da interface) é o que importa para o mundo externo.
- Ex: pedir o GPA a um Estudante — não importa se veio de papel, banco de dados ou sistema online; o resultado é o mesmo.
