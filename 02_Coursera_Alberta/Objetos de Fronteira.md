Objetos situados no limite entre o sistema interno e o mundo externo.

## Responsabilidades
- **Interfaces com Usuário (UI):** Capturar entradas do usuário e exibir dados visuais.
- **Sistemas Externos:** Comunicação com web services, requisições HTTP, banco de dados ou sensores.

## Importância
- Isolar a lógica do sistema das mudanças em APIs externas ou frameworks de interface visual.
