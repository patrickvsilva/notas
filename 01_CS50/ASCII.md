Padrão antigo (*American Standard Code for Information Interchange*) que mapeia caracteres (letras, dígitos, pontuação) para números — tipicamente 7/8 [[Bit e Byte|bits]] (~256 símbolos).

## Ideia Central
- Computador só tem `0`/`1`; humanos combinaram: `'A' = 65`, `'B' = 66`… `'a' = 97` (minúsculas = maiúsculas **+ 32** → um bit na coluna 32).
- Mesmo padrão de bits: calculadora vê número; editor de texto vê letra — **contexto** (o programa) decide.
- Ex: bytes `72 73 33` → `HI!`

## Quando
- **Usar:** entender texto “por baixo” e interoperabilidade básica em inglês.
- **Evitar:** como único padrão mundial — insuficiente para outros idiomas → [[Unicode]].
